# web/ — UI·창 관리 계층 (명세서 §11)

대시보드 앱 `/app` 과 홈 `/` 의 화면이다. 두 시안은 별개이며 상태·스타일을 공유하지 않는다 (명세서 §8).

## 스택

프레임워크·빌드 도구 없음. 브라우저 ES 모듈과 순수 CSS 만 쓴다.

- Node·package.json·잠금 파일이 없다. CONTRIBUTING §1 의 Node 버전·패키지 관리자 결정을 미룬 상태다.
- 외부 CDN 을 불러오지 않는다. 폰트는 설치된 한글 폰트를 순서대로 시도한다.
- FastAPI 가 `/`, `/app`, `/static` 으로 제공한다 (`src/axport/api/pages.py`).

## 파일

```
web/
├── index.html                 /app 셸 — 앱바·바탕화면·창 레이어·live 영역
├── css/
│   ├── tokens.css             색·간격·타이포·버튼·상태색·창 크기 (단일 출처)
│   └── app.css                바탕화면·창·책갈피 탭·상태 화면
└── js/
    ├── app.js                 부트스트랩, 애니메이션 줄이기, 설정 초기화
    ├── api.js                 서버 호출만. 판정·계산 없음
    ├── window-manager.js      창 공통 컴포넌트
    ├── bookmark-tabs.js       책갈피 탭 8개
    ├── analysis-window.js     상단 맥락 + 메인 종합판정 + 탭 화면
    ├── desktop.js             바탕화면 아이콘·빈 상태·업로드·평가 대상 선택
    └── screens.js             로딩/빈/오류/자료부족/평가보류/미구현 화면
```

## 계층 경계 — 반드시 지킬 것

- **판정·계산 로직을 이 폴더에 넣지 않는다** (명세서 §11). 점수 계산, 가중치 적용,
  임계값 비교, 결측 보정을 하지 않는다.
- 화면은 서버가 준 `state` / `display_label` / `reason_code` 를 **그대로 표시**한다.
- 값이 없는 자리를 `0` 이나 예시 수치로 채우지 않는다. `?? 0` 같은 기본값 치환을 쓰지 않는다.
- 화면과 보고서는 같은 평가 실행(`run_id`)을 참조한다.

`tests/test_app_shell.py` 가 이 규칙들을 검사한다. `weight`·`threshold`·`score =`
같은 패턴이 `web/js/` 에 나타나면 테스트가 실패한다.

## 창 관리자

| 기능 | 조작 |
|---|---|
| 이동 | 제목줄 드래그 / `Alt+Shift+방향키` (Ctrl 함께 누르면 크게) |
| 크기 조절 | 오른쪽·아래·모서리 손잡이 / `Alt+Shift+ +`·`-` |
| 최대화 | 제목줄 더블클릭 / □ 버튼 / `Alt+Shift+↑`(창이 맨 위일 때) |
| 최소화 | – 버튼 / `Alt+Shift+M` → 하단 창 목록에서 복원 |
| 닫기 | ✕ 버튼 / `Alt+Shift+W` |
| 창 배치 초기화 | 앱바 버튼 |

- 최소 창 크기: `--win-min-w 480px` / `--win-min-h 320px`
- 조작부가 화면 밖에 갇히지 않게 좌표를 보정한다 (`clamp`, `KEEP_VISIBLE_X`)
- 창 위치·크기를 `localStorage` 에 저장하고, 화면 크기가 바뀌면 `reflowAll` 로 보정한다
- `localStorage` 가 막힌 환경(공용 PC·시크릿 창)에서도 화면은 뜬다

### 중복 실행 정책 — 하나로 고정

같은 `key` 의 창을 다시 열면 **새 창을 만들지 않고 기존 창을 활성화**한다.
같은 평가 실행을 두 창에서 따로 보면 수치가 갈라져 보일 수 있기 때문이다 (명세서 §6).
최소화된 창이면 복원한 뒤 활성화한다.

## 책갈피 탭

종합판정 / 수출실적 / 시장성 / 관세·원산지 / 수출규제 / 거래처 / 수익성·환율 / 공급·물류

- 창 안의 오른쪽 열에 있으므로 창을 옮기면 **함께 움직인다**
- 선택 탭은 색상 외에 **형태**(왼쪽 띠 4px→8px, 들여쓰기, 글꼴 굵기)와
  **텍스트 마커 `▸`**, `aria-selected`, 스크린리더용 "선택됨" 문구로 구분한다
- 창 높이가 작으면 탭 영역이 스크롤된다
- 방향키로 이동, `Home`·`End` 로 처음·끝
- **탭 전환은 화면만 바꾼다.** 기업·제품·목적국·평가 실행은 창(`record.context`)이
  들고 있으며 탭 모듈은 이 값을 모른다

## 상태 화면 — 서로 다른 화면

| 화면 | 마크 | 언제 |
|---|---|---|
| 로딩 | `…` | 요청 진행 중. 이전 결과를 최신처럼 보여주지 않는다 |
| 빈 상태 | `○` | 데이터가 아직 없음. 오류가 아니다 |
| 오류 | `!` | 실패. 오류 코드·단계와 **다시 시도** 경로를 준다 |
| 자료 부족 | `△` | 입력·외부 자료가 없어 계산 불가. 필요한 입력·자료를 나열 |
| 평가 보류 | `‖` | 규칙·설정 미확보·미승인이라 계산을 시작하지 않음 |
| 미구현 | `·` | 아직 만들지 않은 화면. 예시 수치로 꾸미지 않는다 |

## 접근성 (명세서 §9)

- 키보드로 창·탭·아이콘 조작. 앱바의 **키보드 조작** 버튼에 단축키 목록
- 활성 창을 색 외에 형태(`●`)와 스크린리더 문구("활성 창")로 표시
- `:focus-visible` 초점 링 3px
- 애니메이션 줄이기 — OS `prefers-reduced-motion` + 앱바 토글 (localStorage 저장)
- 색상만으로 상태를 구분하지 않는다. 모든 상태 배지에 마크 + 문구
- `aria-live="polite"` 영역으로 창·탭 전환을 문구로 알린다
- 공용 PC 고려 — **화면 설정 초기화** 로 저장된 설정을 지운다

## 홈 화면 (`/`) — 앱과 별개 시안

`web/home/index.html` + `css/home.css` + `js/home.js` + `js/home-3d.js`. 앱 파일을 수정하지 않았다.

- 네이비 히어로 + 중앙 **CSS transform 3D** 오브젝트 (라이브러리·외부 모델 없음, 1,496 bytes)
- `home-3d.js` 는 동적 import — 실패·미지원·애니메이션 줄이기면 **정적 SVG 대체** 화면
- 스크롤 이후 흰 배경의 소개·흐름·원칙 섹션, 우측 상단 **대시보드 앱 열기**
- 앱 진입 로딩: `/health` 를 실제로 호출해 준비 상태를 표시하고 즉시 이동. 고정 대기 없음.
  실패 시 이유(연결 실패·HTTP 상태·설정 오류)와 **다시 시도 / 홈으로** 버튼
- 공통 토큰(`tokens.css`)만 공유. 홈·앱은 상태를 공유하지 않는다

## 시연 데이터 환경 (명세서 §10)

- 바탕화면·업로드 창·분석 창에 `시연 데이터 환경` 안내. 서버 `demo_mode` 가 true 일 때만 표시
- 지표·출처 배지: 실제 자료(●) / 사용자 입력(◐) / 시연 데이터(◌) / 가정값(◇)
- `localStorage` 는 UI 편의 저장(`STORAGE_SCOPE`)이며 기업 계정 저장이 아니다

## 남은 것

- 탭별 수치·차트·표 — 시장성·수출실적 탭만 실제 값. 나머지 4개 탭은 소스 미검증으로 평가 보류 표시
- 컬럼 매핑 확인 UI — 서버 `POST /uploads/{id}/mapping/confirm` 는 동작하지만
  화면은 아직 자동 매핑이 확정된 경우만 처리한다
- 브라우저 자동 테스트 없음. 드래그·리사이즈·키보드는 **수동 확인** 대상이다
