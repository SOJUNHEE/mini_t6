무엇을 하는 서비스인가

기업의 제품·거래·실적 데이터를 표준 엑셀 양식으로 받아, HS 코드와 대상국을 기준으로 규제 · 시장성 · 가격 · 물류 · 안정성 다섯 항목을 확인합니다. 결과는 항상 판단 근거·계산식·자료 출처와 함께 표시됩니다.

규제
필수 조건 검토

허가·원산지 등 법적 조건. 점수로 상쇄되지 않습니다.

시장성
대상국 교역 실적

검증된 관세청 통계로 수출·수입 추이를 봅니다.

가격
관세·원가·환율

자료 검증 전까지 평가 보류로 표시됩니다.

물류
납기·운임

기업이 올린 물류 시트를 근거로 합니다.

안정성
국가·거래처

거래 상대 대조 자료 검증 후 평가합니다.

분석 흐름

  1. 1
    업로드

    표준 양식(.xlsx). 형식·크기·셀 수를 서버가 검증합니다. 매크로·수식은 실행하지 않습니다.

  2. 2
    검증

    숫자·날짜·중복·범위·연결 오류를 행 번호와 함께 돌려줍니다. 빈칸을 0으로 채우지 않습니다.

  3. 3
    매핑 확인

    컬럼 자동 매핑은 후보만 제시합니다. 불명확한 연결은 사용자가 확정합니다.

  4. 4
    평가 대상 선택

    기업 + 제품 + 목적국 + 거래 조건 + 기준일. 거래 조건이 없으면 시장 탐색으로 표시합니다.

  5. 5
    3층 판정

    필수 조건 검토 / 사업적 적합도 / 근거 충족 상태. 화면과 보고서는 같은 평가 실행을 참조합니다.

지키는 원칙

  • ✓구분 실제 값 0 · 미입력 · 미평가 · 해당 없음 · 조회 실패를 절대 같은 값으로 표현하지 않습니다.
  • ‖보류 판정 규칙·점수 기준이 승인되기 전에는 계산을 시작하지 않고 그 사실을 표시합니다.
  • △부족 자료가 없으면 임의 값으로 채우지 않고 필요한 입력을 알려 줍니다.
  • !장애 외부 API 장애 시 샘플 자료로 바꿔 실제 결과처럼 보이게 하지 않습니다.
