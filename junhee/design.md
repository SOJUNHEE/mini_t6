# 디자인 기본 원칙

세부 디자인은 추후 변경한다. 아래 최소 규칙을 공통 적용한다.

## UI 통일성

- 한글·영문을 지원하는 공통 폰트를 사용하고 대체 폰트를 지정한다. 제목·본문·보조문구의 크기와 행간은 공통 스타일로 관리한다.
- 같은 역할의 버튼은 높이·여백·모서리·글자 크기를 통일한다. 기본 버튼 높이는 40px 이상으로 한다.
- 텍스트와 아이콘은 일정하게 정렬하고, 긴 문구·한글·영문·창 크기 변경에도 겹치거나 잘리지 않게 한다. 필요한 경우 줄바꿈을 허용한다.
- 공통 색상·간격·입력창·버튼 스타일을 재사용한다. 상태는 색상뿐 아니라 문구로도 표시한다.

## 메인 대시보드

- 기업 데이터와 HS CODE 입력 후 메인 화면에는 **규제, 시장성, 가격, 물류, 안정성** 5개 요약 항목만 표시한다.
- 각 항목은 **핵심 결과 1개와 짧은 설명 1줄**로 구성한다. 상세 표·다수의 차트·세부 지표는 메인에 나열하지 않는다.
- 평가 대상 기업·제품·HS CODE·대상국·기준일은 상단에 간결하게 표시한다.
- 상세 수치·차트·판정 이유·출처는 창 오른쪽 책갈피형 하위 탭에서 확인하도록 한다.
- 자료가 부족한 항목은 값을 임의로 채우지 않고 ‘자료 부족’ 또는 ‘평가 보류’로 표시한다.

이 문서는 표시 원칙만 정의한다. 5개 항목의 계산식·판정 기준은 별도 명세에서 정한다.
