5. 외부 자료로 못 채우는 영역 — 설계 판단 필요
================================================================

  메인 대시보드 5개 항목 중 아래 둘은 공개 API 로 채울 수 없습니다.

  물류비·운임
    해수부 선박운항정보는 스케줄만 제공합니다.
    실제 운임·납기는 기업 엑셀(물류 시트)로 받아야 합니다.

  제품 가격
    반도체 시세는 Finnhub 로 기업 주가 간접 추정만 가능합니다.
    제품 단가는 기업 엑셀(원가·비용 시트)에 의존합니다.

  원산지 판정 (FTA PSR)
    한국 FTA 원산지결정기준 데이터 소스가 아직 없습니다.
    FTA-PASS 또는 fta.go.kr 수기 참조가 현재 유일한 방법입니다.

  → design.md 원칙대로 '자료 부족' / '평가 보류' 로 표시하고
    임의의 값으로 채우지 않습니다.
